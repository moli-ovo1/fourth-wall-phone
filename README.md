# moli小手机

当前版本：0.4.17

本版新增：
- 四个内置联系人自动初始化
- 微信式聊天列表
- 点击联系人进入私聊
- 本地测试消息发送
- 按酒馆当前聊天档隔离保存会话
- 最后一条消息预览与时间

本版不调用 AI，不消耗模型 Token。

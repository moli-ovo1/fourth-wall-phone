# moli小手机

一个面向 SillyTavern 的场外通讯扩展。

当前版本：`0.1.0` 骨架测试版。

## 当前已实现

- 可拖动悬浮球
- 点击悬浮球打开 / 关闭手机面板
- 点击面板外自动关闭
- 手机面板可通过顶部导航栏拖动
- 悬浮球与面板位置持久化
- 基础首页
- 基础设置页入口

当前阶段尚未接入联系人、聊天数据、API、自动行为等正式功能。

## 安装

在 SillyTavern 的扩展管理界面中，从 Git 仓库安装本扩展。

仓库：

`https://github.com/moli-ovo1/fourth-wall-phone`

## 开发说明

当前优先验证扩展环境下的悬浮入口与面板交互。功能将按 `SPEC.md` 逐步实现。
